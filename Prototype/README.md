# EduTrack - Initial Prototype

EduTrack is a C++ and Data Structures based student management system designed to manage student academic records and provide basic performance analysis.

## Current Prototype

This is the initial working prototype of the EduTrack project. It demonstrates the basic student record management functionality.

## Features

- Add student records
- View student records
- Search student using Student ID
- Calculate student grade
- Calculate class average
- Find the highest-performing student
- Store student records using C++ STL Vector

## Concepts Used

- C++
- Object-Oriented Programming (OOP)
- Classes and Objects
- STL Vector
- Linear Search
- Basic data processing

## Future Development

The following features will be integrated during further development:

- Sorting algorithms for student ranking
- Stack for undo/recent operations
- Queue for managing sequential requests
- File handling for storing records permanently
- More detailed academic performance analysis

## Project Status

Initial working prototype developed for Phase-I of the EduTrack PBL project.

Further modules will be implemented in the upcoming development phases.
